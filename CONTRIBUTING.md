# Contributing

We welcome contributions! Please follow these simple guidelines when submitting changes.

## Workflow

1. Fork the repository.
2. Create a new feature branch for your changes (`git checkout -b feature/my-feature`).
3. Commit your changes. 
4. Push to your fork and submit a Pull Request.

## Commit Guidelines

- **No AI Attribution**: Do not mention in any commit — subject or body — that the code was written, modified, or reviewed by AI (e.g., no "AI-generated" or `Co-Authored-By: Claude`).
- Write clear, imperative commit messages explaining *why* a change was made over *what* was changed.
